<h1>Simple calendar to practice your skills</h1>

<p>This month calendar is intended for training CRUD skills using SQLite Cloud</p>

<p>The calendar opens up a modal and allows CRUD operations in SQLite Cloud</p>

<p>For further usage you will need an APIKey variable that comes automatically when you create a database in SQLite Cloud</p>
<p>The easy-to-use layout of the cloud gives a nice user experience that I highly recommed if you want to train SQL-statements on the browser without a backend server</p>
